# DemoBet88 Demo Bot 产品介绍

## 0. 版本说明（v3.0）
本版提供「管理后台」：客户用账号登入网页后台，不需要碰 Google Sheet。每个品牌有超级管理员和管理员两种角色，品牌方可自行开设员工账号。后台可发布排程公告、上传素材（自动转 Telegram file_id）、编辑菜单按钮/欢迎页/FAQ/活动，bot 同步生效。总览数据来自 bot 真实记录。

## 1. 产品定位
DemoBet88 是一个 **Telegram Bot 功能展示 Demo**，由 M2E Marketing / MJH & Co（吉隆坡）制作，用于向 iGaming / 线上娱乐平台潜在客户展示「Telegram 会员运营机器人」的能力。它不连接真实平台，所有数据存于程式记忆体（重启即清空），目的是让客户用自己的手机亲手体验流程。

## 2. 技术栈
- Node.js 18+、Telegraf 4.x、Express、Multer、dotenv
- 部署：GitHub 私有库 + Railway 自动部署（含健康检查 HTTP 服务）
- 无外部数据库、无 Google Sheet：后台配置存 JSON（DATA_DIR，Railway 挂 Volume 可持久），会员资料在记忆体
- 内置排程器每 30 秒检查一次到期公告
- HTML parse mode，全局 `bot.catch` 错误处理，`bot.launch()` 不 await

## 4. 内部团队协作预览（手动点击，不会自动发送）
入口「🛠️ 内部功能展示」：
- **今日发文排程**：图 + 硬销文案，标注待内容同事确认（@content_team_lead）
- **数据汇报**：每日关键指标示例
- **工作分配**：任务派发示例
每项末尾注明「正式运作时会在固定时间自动发送到工作群」。

## 4b. 管理后台（desk 网页）
- 工作总览：新增用户、绑定Giftcode、签到、互动人数，趋势图，待办提醒
- 发文排程：草稿/确认排程、素材选择、Telegram 预览、发送测试、失败原因显示
- 素材库：图片(<=10MB)/视频(<=50MB) 上传，自动取得 file_id
- 机器人设置：菜单按钮（增删/排序/类型：内置功能、文字内容页、外部链接）、欢迎页、FAQ、活动（标题、内容、图片、结束时间、目标、大奖）
- 操作记录
- 账号与权限：超级管理员 / 管理员两级，品牌方自己开设和停用员工账号，操作记录写明操作人，登入含错误次数限制
- 发布位置：预先设置常用群组/频道，发文时下拉选名称，并可一键测试 bot 是否能发布
- 素材：发文时直接拖入图片/视频，自动存入素材库；保留 30 天后自动清理（使用中的不清理）；文件存在 Telegram，不占服务器空间
- 发送方式：立即发送 / 定时发送 / 存为草稿

## 5. 现场展示建议路线
/start → Giftcode → 签到 → 抽奖 → 邀请好友 → 限时活动 → 内部功能展示。

## 6. 配置（环境变量）
| 变量 | 说明 |
|---|---|
| BOT_TOKEN | 必填，BotFather 取得 |
| ADMIN_PASSWORD | 必填，后台登入密码 |
| STORAGE_CHAT_ID | 素材上传用聊天ID，私聊 bot 发 /chatid 取得 |
| DEFAULT_TARGET | 选填，公告默认发布位置 |
| DATA_DIR | 后台数据目录，Railway 挂 Volume 到此路径 |
| BRAND_NAME | 品牌名，默认 DemoBet88 |
| WELCOME_IMAGE_URL | 选填，欢迎 banner（file_id 或直链） |
| ACTIVITY_IMAGE_URL | 选填，活动 banner |
图片素材统一在后台素材库上传，不再需要手动取 file_id。

## 7. 已知限制
- 会员资料在记忆体，重启清空；后台配置需挂 Volume 才能保留
- 活动倒数、目标、大奖、内容均在后台设定
- 一个服务对应一个品牌；多品牌即多套部署
- 不含风控异常标记、不接真实平台 API、无自动排程
- Railway 变量缓存问题：读不到变量时换新变量名；启动 log 有 `[环境变量检查]`

## 8. 从 Demo 到正式版
正式开发需客户提供：平台 API 文档与串接权限、积分/奖励规则、FAQ 与视频素材、品牌与官网链接。可加：Google Sheet 排程 + cron 自动发文、工作群提醒、数据记录与统计（参考已落地的 Josephy x MYB7 频道项目）。
